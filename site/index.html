01

添加软件源

仅需一次配置。之后用 apt upgrade 接收新版本。

bash — quick start 
sudo install -d -m 0755 /etc/apt/keyrings

curl -fsSL https://repo.wennie99s.top/wispw-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/wispw.gpg >/dev/null

echo "deb [signed-by=/etc/apt/keyrings/wispw.gpg] https://repo.wennie99s.top stable main" \
  | sudo tee /etc/apt/sources.list.d/wispw.list

sudo apt update
支持 Debian 12/13 与 Ubuntu 22.04/24.04/26.04 完整说明 ↗

03

验证来源

仓库元数据由 WispW APT 签名。把指纹和本地 key 对照一次，之后交给 APT。

OpenPGP fingerprint EC40 94DD 2B7D A593 94CC 65F9 5FF3 4D62 F749 ABA6

安装后可以手动验证签名：

gpgv --keyring /etc/apt/keyrings/wispw.gpg \
  /var/lib/apt/lists/repo.wennie99s.top_dists_stable_InRelease

这是第三方软件源，不是 Debian/Ubuntu 官方仓库。建议只在明确需要时添加。
